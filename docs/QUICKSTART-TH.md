# วิธีใช้งาน (Quickstart ภาษาไทย)

> สรุปสั้น: **คุณไม่ต้องรันคำสั่งเอง** แค่เตรียมรูป + บอก AI เป็นภาษาไทย แล้ว AI จะทำทุกอย่างให้
> (คำสั่งบรรทัดเดียวในหน้าเอกสารนี้มีไว้สำหรับคนที่อยากรันเองเท่านั้น)

---

## 1. วิธีที่ง่ายที่สุด — แนบรูปในแชท (แนะนำ)

1. แนบรูปสินค้า/อาหาร ในแชทของ Arena (แนบได้หลายรูป)
2. พิมพ์บอก AI ประมาณนี้:

```text
ทำรูปจากรูปที่แนบ ให้เป็นภาพเมนู 1:1 ขนาด 2048px jpeg
สินค้า: กาแฟ Cold Brew แก้วสูง ใส่น้ำแข็ง + เปลือกส้ม 1 เส้น
อยากได้: ดูน่ากิน ถ่ายโทนแสงเช้า ธรรมชาติ ให้ทุกใบสไตล์เดียวกัน
```

3. AI จะโชว์ **plan** (ตัวอย่าง prompt ทุกใบ) ให้ดูก่อน → ตรวจแล้วพิมพ์ `สร้างรูปตาม plan ได้เลย`
4. เสร็จแล้ว AI จะส่ง **zip + contact sheet** ให้ → ดูรูปทั้งหมดได้จากไฟล์เดียว

**แบบนี้เหมาะกับ:** งานด่วน 1-10 รูป ที่ยังไม่มีตารางคำขอ

---

## 2. มีรูปอยู่ในเครื่องแล้ว — วางในโฟลเดอร์

```text
inbox/
  2026-09-24-cafe/          <- ตั้งชื่ออะไรก็ได้ (ภาษาอังกฤษ)
    cold_brew.jpg           <- วางรูปได้เลย ไม่ต้องตั้งชื่อตามตาราง
    sourdough.jpg
```

แล้วพิมพ์บอก AI: `ทำรูปจากโฟลเดอร์ inbox/2026-09-24-cafe เป็นรอบ 2026-09-24-r01`

AI จะสร้างตารางคำขอให้อัตโนมัติ (1 รูป = 1 บรรทัด) แล้วโชว์ plan ให้ตรวจ
ถ้าอยากให้คำอธิบายละเอียดขึ้น ก็แก้บรรทัด `description` ในตารางที่ AI สร้างให้

**แบบนี้เหมาะกับ:** มีรูปเยอะ แต่ยังไม่อยากนั่งกรอกตาราง

---

## 3. งานจริงจัง — ใส่ตารางคำขอเอง (คุมได้ทุกอย่าง)

1. คัดลอกไฟล์ตาราง: `templates/requests.csv` → `inbox/<ชุดงาน>/requests.csv`
2. วางรูปอ้างอิงใน `inbox/<ชุดงาน>/`
3. กรอก **1 บรรทัด = 1 รูป** (เปิดด้วย Excel/Google Sheets ได้)

| คอลัมน์ | ใส่อะไร | ตัวอย่าง |
| --- | --- | --- |
| `id` | รหัสสินค้า (ห้ามซ้ำ) | `CB-250` |
| `item_name` | ชื่อสินค้า | `Cold Brew Coffee 250ml` |
| `use_case` | อยากได้ภาพแบบไหน (ดูตารางด้านล่าง) | `food-hero` |
| `description` | **สำคัญสุด** อธิบายสั้น ๆ แต่ชัด: สี วัสดุ ทรง ร้อน/เย็น เครื่องตกแต่ง | `cold brew over ice in a tall glass with orange peel` |
| `ref_images` | ชื่อไฟล์รูปอ้างอิง (คั่นด้วย `;` ถ้าหลายรูป) | `refs/CB-250.jpg` |
| `aspect` | สัดส่วนภาพ | `1:1`, `4:5`, `16:9` |
| `delivery_px` | ขนาดด้านยาว (พิกเซล) | `2048` |
| `format` | นามสกุลไฟล์ (`png` สำหรับพื้นหลังโปร่งใส/โลโก้) | `jpeg` |
| `text_verbatim` | ข้อความที่ต้องขึ้นในภาพ **เป๊ะ ๆ** | `COLD BREW 250ML` |
| `must_keep` | (แก้รูปเดิม) ห้ามเปลี่ยนอะไร | `label, bottle shape` |
| `must_avoid` | ห้ามมีอะไร | `extra bottles, text` |
| `asset_type` | เอาไปใช้ที่ไหน | `marketplace listing` |
| `priority` | `high` / `medium` / `low` | `high` |
| `notes` | หมายเหตุถึง AI | `hero for the new listing` |

4. พิมพ์บอก AI: `ทำ intake โฟลเดอร์ inbox/2026-09-24-cafe เป็นรอบ 2026-09-24-r01 แล้วโชว์ plan ให้ดูก่อน`

## AI จะทำอะไรให้ (ขั้นตอนที่เกิดขึ้นจริง)

| ขั้น | AI ทำอะไร | ได้ไฟล์อะไร |
| --- | --- | --- |
| 1. Intake | อ่านตาราง + คัดลอกรูปเข้าโฟลเดอร์รอบ | `rounds/<รหัส>/refs/` |
| 2. Plan | สร้าง prompt ทีละรูป + ตรวจคุณภาพ prompt | `plan.md`, `plan.json` |
| 3. ตรวจ (คุณตรวจ) | โชว์ prompt ให้ดูก่อนสร้าง | — ยังไม่เสียโควตา |
| 4. Generate | สร้างรูป **ไม่เกิน 10 รูปต่อรอบ** | `raw/` |
| 5. Optimize | บีบอัด/ย่อ/ขยายให้ได้สเปก แล้วลบไฟล์ต้นฉบับ | `out/` |
| 6. Review | รวมรูปทั้งรอบเป็นรูปเดียว | `review/contact-sheet.jpg` |
| 7. Verify + Deliver | ตรวจครบ/ขนาดถูก แล้วรวมส่งมอบ | `review/*-delivery.zip` |

**ผลลัพธ์สุดท้ายอยู่ที่:** `rounds/<รหัสรอบ>/review/`

- `contact-sheet.jpg` = ดูรูปทั้งรอบในไฟล์เดียว
- `verify-report.md` = รายงานว่าครบไหม ขนาดเท่าไร
- `<รหัส>-manifest.csv` = รายการรูป + prompt ที่ใช้สร้าง
- `<รหัส>-delivery.zip` = **ไฟล์ส่งมอบ** (รูป + รายการ + plan)

## กติกา 3 ข้อที่ต้องรู้

| กติกา | ความหมาย |
| --- | --- |
| **10 รูป / รอบ** (ไม่ใช่ต่อ session) | งาน 25 รูป = 3 รอบ; รอบหนึ่งทำเสร็จก่อนค่อยเริ่มรอบใหม่ · ถ้าสร้างรูปไม่ตรงแล้วต้องสร้างใหม่ = เสีย 1 สล็อต |
| **128 MB / 10,000 ไฟล์ ต่อ session** | ระบบลบไฟล์ต้นฉบับทุกรอบ + ใช้ contact sheet 1 ไฟล์แทนการเปิดรูปทีละใบ · ไม่ทำตามนี้ ไฟล์ส่วนเกินจะไม่ถูกบันทึก |
| **ใช้เครื่องมือสร้างรูปของ Arena เท่านั้น** | ไม่ใช้ OpenAI API และไม่ต้องใส่ API key ใด ๆ |

## ปรับสไตล์ให้เป็นแบรนด์คุณ (ทำครั้งเดียว)

เปิด `templates/brand.json` แก้ 3-4 บรรทัดนี้ แล้วทุก prompt จะใช้ร่วมกันทั้งชุด:

```json
{
  "brand_name": "ชื่อแบรนด์ของคุณ",
  "campaign": "โปรเจกต์/แคมเปญ",
  "look": {
    "palette": "โทนสีที่ใช้",
    "materials": "พื้นผิวที่ต้องการ",
    "mood": "อารมณ์ภาพ"
  }
}
```

## ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
| --- | --- |
| รูปไม่ตรงที่อธิบาย | เขียน `description` ให้ชัดขึ้น: สี · วัสดุ · ทรง · ร้อน/เย็น · เครื่องตกแต่ง · พื้นหลัง |
| ได้ภาพไม่ครบตามจำนวน | บอก AI ว่าต้องการกี่รูป — AI จะแบ่งเป็นหลายรอบให้ |
| ข้อความบนฉลากผิด/มั่ว | ใส่ `text_verbatim` เป็นข้อความเป๊ะ ๆ (และควรพิมพ์ทับด้วยโปรแกรมออกแบบอีกครั้งถ้าสำคัญ) |
| อยากแก้รูปเดิมเล็กน้อย | ใช้ `identity-preserve` หรือ `precise-object-edit` + ใส่ `must_keep` ว่าห้ามเปลี่ยนอะไร |
| อาหารดูแห้ง/ไม่น่ากิน | เพิ่มใน description: ความเงา, ไอน้ำ(ของร้อน), หยดน้ำ/น้ำแข็ง(ของเย็น), เครื่องตกแต่งสด |
| รูปใหญ่/ไฟล์หนักเกิน | AI จัดการให้แล้ว (บีบอัด + ลบต้นฉบับ) — ถ้าไฟล์เยอะมาก บอกให้ AI `prune` ก่อนเริ่มรอบใหม่ |
| งานไม่จบใน session เดียว | เริ่ม session ใหม่แล้วบอก AI ให้ทำต่อจาก `rounds/<รหัสรอบ>/` (prompt ถูกเก็บไว้แล้ว) |

## สำหรับคนที่อยากรันคำสั่งเอง (ไม่บังคับ)

```bash
python3 tools/igp.py intake --name <ชุดงาน> --round-id <วันที่>-r01 --clean   # รับงาน + ทำ plan
# ... สร้างรูปไม่เกิน 10 รูปลง rounds/<รหัส>/raw/ ...
python3 tools/igp.py optimize --round rounds/<รหัส> --delete-source --upscale-to-spec
python3 tools/igp.py sheet    --round rounds/<รหัส>     # contact sheet 1 ใบ
python3 tools/igp.py verify   --round rounds/<รหัส>     # ตรวจครบ/ขนาด
python3 tools/igp.py deliver  --round rounds/<รหัส>     # รวม zip ส่งมอบ
python3 tools/igp.py budget                             # เช็คโควตาไฟล์/session
python3 tools/igp.py status                             # ดูรอบทั้งหมด
```

เช็คว่าระบบพร้อมใช้: `bash tools/smoke_test.sh`
รายละเอียดเชิงลึกสำหรับ AI: `AGENTS.md` และ `skills/arena-imagegen/SKILL.md`
